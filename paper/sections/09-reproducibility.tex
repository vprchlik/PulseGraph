\section{Registration and reproducibility}
\label{sec:repro}

The repository \url{https://github.com/vprchlik/PulseGraph} holds the protocol with its dated additions. Its
registered bytes are byte prefixes of the file as committed and were verified by each run's gate. It also
holds the declaration files of every family and the study code with its offline tests. For each study there is
an evidence package. It holds the frozen frame, manifest and selection, the panel's status file, the readiness
and gate records, and the run's state with the SHA-256 of every checkpoint. Beside them sit the inference
directory with the family table, the per-series paired differences and the secondary tables, the integrity
recomputation, the results page and a provenance file with the approvals, the commands and their times.

Every score of the three runs was recomputed from the saved forecasts by a separate script with no
disagreement. A script that shares no code with the pipeline recomputed the Study 3 census from the raw
captures. Each post-hoc analysis has its own directory with its specification, command, outputs and
provenance.

Not in the tree are the checkpoints that hold every forecast, 300 for GitHub (one results file of 433,172,286
bytes), 540 for the grid, 209 for npm and 300 for NYC 311, the raw captures and the target signals of the npm
and NYC 311 series. The results file, the 1,049 checkpoints of the grid, npm and NYC 311 runs and the two
target-signals files are the release assets listed with their sizes and SHA-256 in
\texttt{reports/release/ASSETS.md}. With them a fresh clone can rerun every inference, integrity check and
post-hoc analysis. In the tree are the aggregated daily counts of the npm and NYC 311 series, context and
targets, under the data statements of Appendices~\ref{app:s2panel} and~\ref{app:s3detail}:
\texttt{reports/study2-npm/panel/daily\_counts.csv} and
\texttt{reports/study3-nyc311/panel/daily\_counts.csv}, each with its provenance file and a test that rebuilds
it byte for byte.

Each run's commands are given by reference to its results page in Appendix~\ref{app:runs}, with the run
record. The number checker asserts every figure in this paper against the files it names, and the figure
script draws every figure from the saved files alone.
